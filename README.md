# Enterprise Network Design & Implementation

## Overview

This project presents an enterprise network designed and implemented using Cisco Packet Tracer.

The network consists of multiple branch locations and demonstrates the implementation of enterprise networking concepts including VLAN segmentation, routing, redundancy, wireless networking and network services.

## Technologies & Concepts

- VLANs
- Inter-VLAN Routing
- OSPF
- HSRP
- EtherChannel
- WLAN / WLC
- DHCP
- DNS
- FTP
- Web Services
- Layer 2 Security
- Cisco Packet Tracer

## Network Design

The project includes network infrastructure for:

- Kuala Lumpur (HQ)
- Malacca
- Penang
- Johor Bahru

The design uses VLAN segmentation and routing to provide connectivity between different departments and locations.

## Network Security

Security-related configurations include:

- VLAN segmentation
- Port Security
- BPDU Guard
- WPA2 wireless security
- Controlled network access
